# Merge365 Edge Bootstrap

Bootstrap script for installing private Merge365 Edge releases.

Usage:

    curl -fsSL https://raw.githubusercontent.com/scharfesicht/Merge365Edge-Bootstrap/main/merge365-edge-bootstrap.sh \
      -o /tmp/merge365-edge-bootstrap.sh

    chmod +x /tmp/merge365-edge-bootstrap.sh

    sudo /tmp/merge365-edge-bootstrap.sh v1.0.0
